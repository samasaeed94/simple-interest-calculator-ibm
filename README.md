# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period of time at a given rate of interest.

This project is developed as part of the IBM Getting Started with Git and GitHub course.

## Features

- Accepts the principal amount from the user.
- Accepts the annual rate of interest.
- Accepts the time period in years.
- Calculates simple interest using the standard mathematical formula.
- Displays the calculated simple interest.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest (percentage).
- **Time:** The time period in years.
